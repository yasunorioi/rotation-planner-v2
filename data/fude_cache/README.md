# 筆ポリゴン キャッシュ (data/fude_cache/)

農林水産省の筆ポリゴン（農地区画データ）を置くディレクトリ。
ほ場ポリゴン編集画面の「筆ポリゴン表示」トグルがここを読む。

## 置き方（規約同意 → ダウンロード → 配置）

1. https://open.fude.maff.go.jp/ を開く
2. 利用規約に同意し、対象市町村を選んで **GeoJSON** をダウンロード
   （アンケート回答が必要なため自動ダウンロードは不可）
3. ダウンロードした GeoJSON を `{市町村コード}.geojson` にリネームしてここに置く
   - 例: 恵庭市 = `01231.geojson`
   - 複数市町村を置いてよい（全ファイルを横断検索する）

## 使い方

- ほ場一覧 → 任意のほ場の「ポリゴン編集」→ 地図をズーム14以上に拡大
- 「筆ポリゴン表示」トグルを ON → ビュー内の筆が橙で表示される
- 目的の筆をクリック → そのほ場のポリゴンとして採用（手描き不要）→「保存」
